# WebDatenbankAktion

Ein Visual-Studio-Projekt zur Durchführung und Verarbeitung von Datenbankaktionen innerhalb einer Webanwendung.

## Beschreibung

Das Projekt **WebDatenbankAktion** beschäftigt sich mit den Grundlagen der Datenbankinteraktion in Webanwendungen. Im Mittelpunkt stehen die Ausführung von Datenbankoperationen, die Verarbeitung von Benutzereingaben und die Kommunikation zwischen einer webbasierten Benutzeroberfläche und einer Datenbank.

## Funktionen

- Verbindung zwischen Webanwendung und Datenbank
- Ausführung von Datenbankaktionen
- Hinzufügen neuer Datensätze
- Bearbeiten bestehender Datenbankeinträge
- Löschen gespeicherter Datensätze
- Verarbeitung von Datenbankabfragen
- Grundlagen der CRUD-Operationen (Create, Read, Update, Delete)

## Technologien

- Microsoft Visual Studio
- Visual-Studio-Projektmappe (.sln)
- Web- und Datenbanktechnologien

## Installation und Ausführung

1. Repository klonen:

   ```bash
   git clone https://github.com/samad-pour/WebDatenbankAktion.git
   ```

2. Die Datei `WebDatenbankAktion.sln` in Visual Studio öffnen.
3. Falls erforderlich, die Datenbankverbindung konfigurieren.
4. Das Projekt erstellen.
5. Die Anwendung mit `F5` starten.
6. Die Webanwendung im Browser öffnen.
